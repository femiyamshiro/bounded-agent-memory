# 合成场景

以下全部为虚构场景，不来自实际记忆或私人聊天。

| 场景 | 合成输入 | 预期结果 |
| --- | --- | --- |
| 一次性限制 | 最早一轮明确“本服务仅限内网”，后面没有重复 | 实施前补读该限制，不能因频率低或不在尾部而忽略 |
| 中段修订 | 早期端口 4100，中段经验证改为 5200 | 保留版本关系；核实修订后使用 5200，不按最新提及次数决定 |
| 重复错误 | 同一个错误配置被重复建议五次 | 不增加可信度，不写成事实 |
| 讨论未决 | “也许可以用方案 Q，尚未测试” | Notion 可记录讨论及待验证状态；不写成已确认长期事实 |
| 记得讨论过 | 用户问“我们是不是聊过 Q？” | 定向找项目讨论和原件；未命中不能断言没讨论 |
| 恢复教训 | 一次失败后通过真实检查定位权限错误并恢复 | 留存已验证根因、适用条件及必要恢复步骤；失败命令自报不是证据 |
| 超额取证 | 关键早期限制超出剩余来源预算 | needs_evidence / uncertain，拒绝截断或假装材料完整 |
| 重启 | 来源 broker 读取一部分后重启 | 同 lease、已耗额度保留、拒绝重复正文交付 |
| 来源漂移 | 补读后某轮内容或终态改变 | lease 失效；不追加新事件；已返回原事件只协调原身份 |
| 终态错误 | 用户说部署完成，但对应轮次 failed | 保留失败状态，不能认定验证成功 |
| 同名项目 | 项目甲和项目乙都有“网关优化” | 先绑定规范项目身份，不能用同名语义命中跨项目复用 |
| 不明回执 | writer 提交后超时 | 查询原事件，保留 fence，不换事件重发 |
| 已有方法 | 当前 Skill 已覆盖本次步骤 | 复用现有内容，不因完成任务就创建新 Skill |
| 草稿合格 | 新方法有来源、适用范围且格式通过 | 只保存未安装草稿；格式检查不等于实际方法验收 |
| 反馈自报 | Agent 说“这条记忆节约了很多时间” | 无有效对照则因果收益未证明；记录真实产物/验证引用，不写收益结论 |

对照试验应预先冻结这些场景的证据和判据。测试期望本身不是模型表现；需要真实执行并与独立固定标准核对。
